# Pacoragroma projects

Claude plugins and skills. Each folder is a self-contained project with its own README and license.

| Project | What it is |
|---|---|
| [day-trader](day-trader/) | 11 Claude skills that work like a small day-trading desk: they scan thousands of charts, track breaking news, time every entry and exit, and replay every outcome before you risk a dollar. Paper trading only. Free, MIT, no signup, no API key. |

## Install (Claude Code)

```text
/plugin marketplace add Pacoragroma/projects
/plugin install day-trader@pacoragroma-projects
```

For manual installs and the Claude apps, see [day-trader/README.md](day-trader/README.md#install).
